## 0. 指标对齐：81 不是"准确率"

主指标是**检查级十类 Macro-AUC**，不是分类准确率，也不是阈值命中率（见 `题目要求.md`）。
"81%" = **public 榜 81 分 = Macro-AUC 0.81**，对应前 10%（约前 76/763 名）。

排名只取决于"同一类里正检查排在负检查前面的比例"，所以：

- 调阈值 / 概率校准 / 优化 F1 → **对分数几乎没作用**；
- 真正起作用的是**秩**：把每一类的正例排得比负例高。

### 明确不做

| 不做 | 理由 |
|---|---|
| 单独换骨干 | 两个不同骨干 valid 都落在 0.792，45 倍算力换 −0.0003；ConvNeXt-S 明显过拟合（train 0.061→0.023 / val 0.060→0.115）；大骨干还挤压 500MB 集成空间与 T4 100ms 余量 |

| 伪标签 / 外部数据 / 医学预训练 | 规则红线 |

## 5. 纪律与风险

1. 选模只用 **longitudinal-dev**（200 患者/1347 检查），不用 valid 反复贪心选模（已实测会过拟合：dev 0.8090 → valid 0.7979）。
2. **每天 2 次提交**，剩余约 4 天最多 6-8 次；每次提交当"信息收集"，别过度解读 ±2 分噪声。
3. 合规红线：只用官方 train、非医学预训练（ImageNet / DINOv2 通用权重）、模型 ≤500MB、单图 ≤100ms（T4）、预训练权重来源 + SHA-256 留痕。
4. 预期管理：现实落点 76~79；免费杠杆（A2/A3）与多样性集成（A1）均已证伪，资源集中在 B1（valid 并入终训）、C2（弱类重加权）与 D1 探针。
