## 决策

保留原三模为当前发布基线。control 尚不满足直接替换、全量终训或消耗榜单提交的证据要求。
下一步按已提交配方跑 weak；相同 dev、相同 seed 和训练流程，仅损失中的 class 1/4/8
权重不同。先比较 weak 与 control 的完整十类 AUC、患者配对差值和子群，再以 valid 确认。
不在这一轮临时搜融合权重、延长 control 或重跑 A2/A3。
