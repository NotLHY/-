## 2. DeepSeek 的数字基本可复核，停止探索的结论不成立

直接复核 `runs/r2_*/evaluation_valid.json` 得到：r2_s42 0.7982581、split43 0.7916169、split44 0.7840666、BCE 0.7845275、strong seed42 0.7809382、strong seed43 0.7806698。均有完整十类 AUC。见 `runs/p5_20261031/prior_evidence_audit.json`。

这些结果支持“这批具体配方没超过当前基线”，不支持“任务或整个模型族已达上限”。需要纠正：

1. **增强与 schedule 混杂**：`runtime._scheduler` 使用 `T_max=config.epochs`。legacy 5 轮与 strong 15 轮同时改变增强、训练长度和学习率轨迹。峰值后移不能证明增强不足；病灶被遮挡只是候选解释，未做单因素消融。
2. **内部验证不是无用**：不同 split 的内部 AUC 面对不同患者，绝对值不能直接排模型。相同 split 的排名冲突应检查逐类、患者构成、抽样不确定性和训练配方；不要按一次反向结果废弃整个验证机制。
3. **主指标被换窄**：官方 valid 有 859 检查、228 患者；≥5 子集有 571 检查、45 患者。最大单患者贡献 89 检查。≥5/≥8 可作固定压力测试，不应替代完整 valid 十类 Macro-AUC，更不能称为 test 代理真值。
4. **两点外推无预测依据**：`test ≈ valid - 5.4` 只是两次历史提交的描述，不能预测新骨干、证明 79 不可达或给出可信成功概率。停止在报告里输出伪精确的“外推 test”。
5. **探索与发布应分开**：单次结果未达到“+0.5 分且置信区间下界 >0”，不足以永久关闭路线。探索候选可根据效应大小、互补性和预算复验；最终发布才要求更强的稳定性证据。
6. **后处理不涨不能否定学习结构**：同一模型输出的 mean/max/logit_mean 不涨，不能推出新双流或可学习融合一定无效；它们的表征和优化不同。但更复杂结构是否值得做仍须对照实验。
7. **历史选择链需要保留**：`local_nocache_base_seed44` 日志明确使用 `macro_auc_reweighted` 选 checkpoint。事后在 valid 上再评一次不能抹去原来的选择过程。本轮 P5 关闭该指标、固定轮数并重新训练，历史材料保留如实记录。
8. **旧统计工具也要审查**：`tools/compare_models.py` 的 bootstrap 在缺类时取剩余类别均值，`_analysis/morning_report.py` 的子集指标也跳过缺类。后续完整十类区间必须显式统计失效重采样，不能把可定义类均值冒充十类 Macro-AUC。

## 4. 新路线候选，待榜单目标确认

不能保证 valid 上升就一定 test 上升。应增加在未见患者上的证据，并减少针对固定验证样本反复挑选。

**验证协议候选**：仅从 train 建立患者互斥、多标签分层的固定折，先检查每类阳性患者与检查数，再训练。筛选阶段共用一折；少数晋级候选做三折 OOF 或配对重复实验。多次随机留出并不自动等于三折 OOF。主指标保持检查级十类 Macro-AUC，辅助报告 AP/PA/多视图、重复检查组、逐类 AUC、患者簇配对 bootstrap。官方 valid 已被反复使用，只能称外部复核集，不能再称从未触碰的盲测集。重新划分不是寻找分数更好看的验证集，所有候选必须共用预先固定的划分。

**模型候选顺序**：

1. 保留 P5 基线，同时探索异骨干。DenseNet-121 已有实现，可作为低开发成本候选；ConvNeXt-Tiny 可作为更明显的表征变化。每种骨干需要合理的学习率与训练预算，不能简单把 B0 的五轮配方移植失败就判死刑。
2. 单独评估输入信息损失：当前 224 全图压缩，优先做一种较高分辨率的受控对照；旧 288 一次失败不能排除所有高分辨率策略。模型最终是否保留仍取决于验证和 T4 实测。
3. 若普通微调的合格对照仍停滞，再考虑通用自监督视觉表征，例如 DINOv2-S，先完成具体权重来源核验和较便宜的特征探针。探针失败不等于完整微调失败，但可帮助分配预算。
4. 官方 train 自监督续训、教师蒸馏是明确可探索的空间；在 0–300 元预算下作为后续候选，不同时铺开。蒸馏价值在于将更强教师的效果压入部署预算，仍要实验证实。
5. 新的增强实验先拆开 erasing、仿射尺度与训练长度；完整 valid 下降的具体组合不应继续重复烧卡。

资料核验：
- [torchvision 0.25 ConvNeXt-Tiny](https://docs.pytorch.org/vision/0.25/models/generated/torchvision.models.convnext_tiny.html)：提供 ImageNet-1K 权重，原分类模型约 28.59M 参数、权重约 109.1MB。不是本任务成绩或 T4 延迟保证。
- [Meta DINOv2 模型卡](https://github.com/facebookresearch/dinov2/blob/main/MODEL_CARD.md) 与 [官方仓库](https://github.com/facebookresearch/dinov2)：记录模型与 Apache-2.0 许可；具体权重的训练数据材料、下载和哈希仍需逐项留存。

算力安排暂按：本地完成基线、数据诊断和小规模筛选；新增预算优先留出 T4 验收，再根据真实吞吐决定是否短租更大显存训练卡。本轮尚未租用或购买服务。
